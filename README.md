# Alex Garcia Gil

I build fast game clients, Premiere Pro tools, and AI agent infrastructure.

## Projects

- **[WOK Client](https://github.com/nzalexgarciagil-ctrl/wok-client)** — the fastest Krunker client. Ever. Uncapped-framerate input handling and frame pacing, patched at the Chromium level.
- **[deadair](https://github.com/nzalexgarciagil-ctrl/deadair-premiere)** — amplitude-based silence and noise removal for Premiere Pro. Free and open source.
- **[rewind](https://github.com/nzalexgarciagil-ctrl/rewind)** — git for Premiere Pro: named branches, auto-snapshots, one-click restore.
- **[pathfinder](https://github.com/nzalexgarciagil-ctrl/pathfinder-premiere)** — free media relinker for Premiere Pro. Fix offline media without opening Premiere.
- **[beeper-poke-bridge](https://github.com/nzalexgarciagil-ctrl/beeper-poke-bridge)** — let your Poke assistant handle every messaging app: WhatsApp, Instagram, X, Telegram, Discord, Signal, iMessage, and more.
- **[farmer-mode](https://github.com/nzalexgarciagil-ctrl/farmer-mode)** — a Claude Code skill that teaches engineering thinking through constraint-driven practice.
- **[pi-extensions](https://github.com/nzalexgarciagil-ctrl/pi-extensions)** — extensions for the pi coding agent: per-repo model, per-repo skill toggles, image cache.

More Premiere Pro extensions: [random-motion](https://github.com/nzalexgarciagil-ctrl/random-motion), [cut-before-markers](https://github.com/nzalexgarciagil-ctrl/cut-before-markers).
